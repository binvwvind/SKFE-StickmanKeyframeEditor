## 1. 界面与基础操作

### 1.1 界面布局
- **画布**：占据屏幕大部分位置，是你创作和预览动画的地方。
- **控制面板（左侧/底部）**：包含导出、添加物体、属性调节、各种高级设置。
- **动画面板（时间轴）**：点击右下角 `🎬 帧动画面板` 打开，用于管理帧和制作动画。
- **历史记录（右上角）**：撤销（↩）和恢复（↪）。

### 1.2 视角控制
- **PC 端**：鼠标滚轮缩放，按住鼠标左键拖动空白处平移视角。
- **移动端**：双指拖动平移，捏合缩放。
- **吸附**：在基础属性中开启“吸附”，拖动对象时会自动对齐其他物体的边缘或中心。

### 1.3 面板操作
- **移动**：拖动面板顶部的横条可以移动面板。
- **自由缩放**：点击面板底部的 `📐 开启自由缩放`，可拖拽面板右下角的 `◢` 调整大小（**注：浏览器会记住此开关状态**）。
- **锁定**：点击 `🔒 锁定面板位置` 防止误触移动。

## 2. 添加与编辑物体

### 2.1 添加物体
展开面板中的 `＋ 添加物体`，你可以添加：
- **火柴人**：核心创作对象。
- **图片**：插入本地图片作为背景或道具。
- **上传配饰**：可以绑定在火柴人关节上的物品（如武器、帽子）。
- **对话框**：气泡文字，支持自定义颜色、渐变、大小和尾巴镜像。
- **摄像机**：用于限制导出画面的范围和比例。
- **内置形状**：圆形、方形、三角形。

### 2.2 基础属性（选中物体后）
- **名称 / 颜色 / 线条**：修改火柴人或形状的基础外观。
- **位置（X / Y）**：可直接输入数字，或点击旁边的 `移动` 按钮调出 ✥ 手柄在画布上拖动。
- **缩放 / 透明**：快速调整大小和透明度。
- **旋转**：可输入精确角度（支持超 360° 多圈旋转），或点击 `↻ 旋转` 调出旋转手柄。
- **水平镜像**：左右翻转。
- **头型**：火柴人专属，在「旋转」下方。可在 `圆 / Vic / TCO / TDL / TSC` 之间点击切换，
  Vic/TCO/TDL/TSC 是跟随火柴人自身颜色的手绘矢量头型，默认正立，可像圆头一样跟随头部关节旋转、
  也支持镜像与实心/内部填充色。**头型粗细是图形自带的，不受「线条」滑块影响；大小只跟「比例 → 头部」走。**
- **层级控制**：`+1层`、`-1层`、`置顶`、`置底`。

## 3. 进阶设置（比例、关节、发光、橡皮擦）

在控制面板中间有一排工具按钮：`层级`、`比例`、`关节`、`发光`、`画笔`、`画布`、`主题`。点击即可展开对应设置。

### 3.1 比例（体形）
- **基础比例**：调整头部大小、手臂长度、腿长、躯干比例。
- **四肢独立**：勾选后可分别设置左手/右手、左腿/右腿的长度，用于制作透视近大远小效果。
- **小手小脚**：开启后火柴人会有手掌和脚掌，可调节手长占比和脚长占比。
- **独立平移头部**：勾选后可使用头部移动手柄单独移动头部（如歪头）。

### 3.2 关节与 IK（反向动力学）
- **关节点**：画布上蓝色的圆点。直接拖动圆点即可调整姿势。
- **关节旋转滑条**：拖动对应关节的滑条精确旋转。
- **关节拉伸**：勾选后拖动关节不仅可以旋转，还能拉长/缩短肢体。
- **隐藏关节点**：勾选后画布上不显示圆点，方便截图。
- **关节固定 (IK)**：开启“启用”后，点击 `左脚`、`右手` 等按钮，该关节就会被“钉”在原地，此时移动躯干，肢体长度会自动伸缩以适应固定的点（红色关节表示已固定）。

### 3.3 发光与特效
- **轮廓外发光**：开启后可设置颜色、透明度、扩散范围。
- **侧面高光**：让火柴人看起来有立体感，可调高光粗细和方向。
- **手部渐变**：让手臂末端呈现渐变颜色。
- **地面阴影**：开启后自动在脚下生成阴影，可独立调节透明度、宽度拉伸、高度拉伸（开启后在“发光”面板展开时可直接在画布拖动阴影）。
- **深色处理**：将左臂和左腿（后方肢体）自动变暗，增强空间感。

### 3.4 画笔（橡皮擦）
- **矢量橡皮擦**：使用圆形笔刷擦除火柴人、图片或形状。
- **直线模式**：只画起点到终点的直线。
- **末端吸附（QuickShape）**：画完后笔尖停在末端不要抬起，会自动吸附成直线、圆、矩形等标准图形；
  按住拖动可改大小和角度，再停一下可在候选图形之间轮换。
- **优势**：擦除是矢量的，不破坏原像素，会跟随物体移动、旋转和缩放。支持撤销和清除本帧/全部擦除。

### 3.5 画布设置
- **背景与网格**：仅改变编辑时的外观，不影响导出结果。
- **画布边界**：开启后，导出仅保留画布框内的内容。可调节比例（1:1、16:9 等）。
- **地面参考线**：画一条绿色的辅助线，方便对齐脚部，同样不影响导出。

### 3.6 主题设置
- 可自定义面板背景、按钮颜色、文字颜色等，支持保存为“我的主题预设”。

## 4. 时间轴与帧动画制作

点击右下角 `🎬 帧动画面板`，顶部是帧列表，底部是操作按钮。

### 4.1 基础帧操作
- **＋ 帧**：在当前帧后插入一个空白/克隆帧。
- **⧉ 复制帧**：复制当前帧。
- **🗑 删除帧**：删除当前帧。
- **多选**：勾选“多选”后，点击帧块可以选中多个帧，支持多选补间、删除、导出 PNG / GIF。
- **拖拽排序**：鼠标按住帧块直接拖动，或触屏长按 300ms 拖动，可以调整帧的顺序。

### 4.2 关键帧（v7.0 起的主力方式）

时间轴现在是「关键帧 + 派生帧」：你只摆两个关键帧的姿势，中间的帧是**算出来的**，不占存储、也不会互相打架。

1. 播放头移到某一帧，点 `◆ 设关键帧`（或按 `K`）—— 当前姿势就锁成了关键帧。
2. 移到另一帧、改姿势，再按一次 `K`；两帧之间立刻出现一整段自动补出来的画面。
3. **主轨 / 子轨**：主轨按 `K` 只给「这一帧参数真的变了」的元件打关键帧；要单独锁住某个元件，切到它的子轨再按 `K`。
4. **段曲线**：点 `▾ 匀速` 改的是**当前这一段**（相邻两个关键帧之间）。先选中元件，曲线只作用于它的这一段，既不会影响别的段，也不会影响别的元件。
5. **删关键帧 ≠ 清空**：删中间的关键帧 → 前后两段自动合并补满；删末尾 → 之后所有帧静止延续这个姿势；删开头 → 之前所有帧都变成它的复制帧。
6. **复制关键帧**得到的是新的关键帧，不是普通帧。

> 旧版的 `✨ 补间` 仍然保留（见下一节），但新工程建议直接用关键帧。

### 4.3 补间动画（自动生成中间帧 · 兼容旧流程）
假设你要让火柴人从 A 点移动到 B 点：
1. 在第 1 帧摆好姿势（A 点）。
2. 点击 `＋ 帧` 创建第 2 帧，把火柴人移到 B 点。
3. 选中第 1 帧，点击 `✨ 补间`，输入补间帧数（如 10），点击确定。
4. **缓动曲线**：点击补间旁边的 `▾ 匀速` 可以切换缓入、缓出、缓入缓出或自定义贝塞尔曲线。
5. **🎯 分部缓动**：点击“分部”，可以单独为位置、缩放、旋转、各个关节设置不同的曲线。

### 4.4 高级动画功能
- 点击 `⚙️ 高级设置`：
- **FPS（帧率）**：调节每秒播放的帧数（默认 12）。
- **洋葱皮**：开启后，画布上会半透明显示前一帧（橙色）和后一帧（蓝色）的残影，方便调整动作。
- **全局属性修改**：勾选后，修改颜色、线条粗细、比例等属性会同步应用到该元件的所有帧。
- **清空所有帧 / 清空非当前帧**：快速重置工程。

## 5. 摄像机与取景框

如果你需要导出特定比例的视频（如 16:9 短视频）：
1. 展开 `＋ 添加物体`，点击 `🎥 摄像机`。
2. 在控制面板调整摄像机的比例（16:9、9:16、1:1 等）。
3. 在时间轴轨道选择器中，选择摄像机所在的子轨道。
4. 此时画布会变成摄像机取景视角。在框内拖动可以平移摄像机，双指缩放或滚轮可以缩放摄像机取景框。
5. 摄像机也可以做动画（打关键帧）。

## 6. 导出与保存

### 6.1 导出图片 / 序列帧
- **导出 PNG / JPG**：点击面板顶部按钮，可选择高清导出（4 倍分辨率）。
- **导出 PNG 序列**：在时间轴高级设置中，将每一帧打包成 ZIP 下载。
- **多选 PNG**：在多选模式下，只导出选中的帧。

### 6.2 导出 GIF
- 在高级设置中点击 `导出 GIF`。
- 可开启“透明底”（背景透明）和“3x 高清”。
- iOS 用户导出后长按图片保存到相册。

### 6.3 导出视频
- **导出 WebM**：支持透明底的视频格式。
- **导出 MP4**：不支持透明底，但兼容性好，可自定义背景色。

### 6.4 保存动作与预设
- **保存动作**：在高级设置底部，输入动作名称（如“跑步”），将当前动作保存到动作库，可随时应用到其他火柴人身上。
- **本地预设**：保存单个火柴人的外观、颜色、比例。
- **保存项目**：
  - **💾 保存项目**：保存到浏览器缓存。
  - **📤 导出项目 / 📥 导入项目**：保存为 `.json` 文件，方便分享或备份。
  - **自动存档**：编辑器每 20 秒会自动将进度保存在浏览器后台，刷新网页不会丢失。

## 7. 快捷键与实用技巧

### 快捷键
| 按键 | 功能 |
| --- | --- |
| `C` | 复制当前选中物体 |
| `Delete` / `Backspace` | 删除当前选中物体 |
| `Space` (空格) | 播放 / 暂停动画 |
| `←` / `→` (方向键) | 切换到上一帧 / 下一帧 |
| `R` | 重置当前选中物体的姿势 |
| `Ctrl + Z` / `Cmd + Z` | 撤销 |
| `Ctrl + Y` / `Cmd + Shift + Z` | 恢复 |
| `Escape` | 关闭弹出的菜单或窗口 |

### 💡 核心技巧
1. **想做复杂的连招？** 给每个火柴人使用**独立的子轨道**（时间轴上的下拉菜单选择）。不同轨道互不干扰。
2. **火柴人太密了总是选错？** 点击上方的“图层列表”图标进行选择，或者在“层级”面板调整图层，将遮挡的肢体放到底部。
3. **橡皮擦提示受限？** 确保你选中了对象。橡皮擦只对当前选中的对象生效，并且关闭擦除模式时不会退出选择。
4. **缩放时想保持比例？** 使用自由缩放，浏览器会自动记住你调整的面板尺寸（强制刷新浏览器即可看到记忆生效）。
5. **避免画面抖动**：补间动画如果生成了不需要旋转的帧（例如原地不动），确保起始帧和结束帧的角度完全一致。
