## 1. 界面与基础操作

### 1.1 界面布局
- **画布**：占据屏幕大部分位置，是你创作和预览动画的地方。
- **控制面板（左侧/底部）**：底部一排 **8 个图标入口** —— 属性 / 元件 / 画笔 / 画布 / 高级 / 项目 / 导出 / 主题。点某个入口就展开对应分区，**再点一次同一个入口即全关**（桌面端只剩左上角一条图标栏，手机端只剩屏幕底部一条图标栏），界面随时能腾干净，不用再找收起按钮。
- **动画面板（时间轴）**：点击右下角 `🎬 帧动画面板` 打开，用于管理帧和制作动画。
- **历史记录（右上角）**：撤销（↩）和恢复（↪）。

### 1.2 视角控制
- **PC 端**：鼠标滚轮缩放，按住鼠标左键拖动空白处平移视角。
- **移动端**：双指拖动平移，捏合缩放。
- **吸附**：在基础属性中开启“吸附”，拖动对象时会自动对齐其他物体的边缘或中心。

### 1.3 面板操作
- **移动**：拖动面板顶部的横条可以移动面板。
- **自由缩放**：点击面板底部的 `📐 开启自由缩放`，可拖拽面板右下角的 `◢` 调整大小（**注：浏览器会记住此开关状态**）。
- **锁定**：点击 `🔒 锁定面板位置` 防止误触移动。

## 2. 添加与编辑物体

### 2.1 添加物体
展开面板中的 `＋ 添加物体`，你可以添加：
- **火柴人**：核心创作对象。
- **图片**：插入本地图片作为背景或道具。
- **上传配饰**：可以绑定在火柴人关节上的物品（如武器、帽子）。
- **对话框**：气泡文字，支持自定义颜色、渐变、大小和尾巴镜像。
- **摄像机**：用于限制导出画面的范围和比例。
- **内置形状**：圆形、方形、三角形。

### 2.2 基础属性（选中物体后）
- **名称 / 颜色 / 线条**：修改火柴人或形状的基础外观。
- **位置（X / Y）**：可直接输入数字，或点击旁边的 `移动` 按钮调出 ✥ 手柄在画布上拖动。
- **缩放 / 透明**：快速调整大小和透明度。
- **旋转**：可输入精确角度（支持超 360° 多圈旋转），或点击 `↻ 旋转` 调出旋转手柄。
- **水平镜像**：左右翻转。
- **头型**：火柴人专属，在「旋转」下方。可在 `圆 / Vic / TCO / TDL / TSC` 之间点击切换，
  Vic/TCO/TDL/TSC 是跟随火柴人自身颜色的手绘矢量头型，默认正立，可像圆头一样跟随头部关节旋转、
  也支持镜像与实心/内部填充色。**头型粗细是图形自带的，不受「线条」滑块影响；大小只跟「比例 → 头部」走。**
- **层级控制**：`+1层`、`-1层`、`置顶`、`置底`。

## 3. 进阶设置（比例、关节、发光、橡皮擦）

在控制面板中间有一排工具按钮：`层级`、`比例`、`关节`、`发光`、`画笔`、`画布`、`主题`。点击即可展开对应设置。

### 3.1 比例（体形）
- **基础比例**：调整头部大小、手臂长度、腿长、躯干比例。
- **四肢独立**：勾选后可分别设置左手/右手、左腿/右腿的长度，用于制作透视近大远小效果。
- **小手小脚**：开启后火柴人会有手掌和脚掌，可调节手长占比和脚长占比。
- **独立平移头部**：勾选后可使用头部移动手柄单独移动头部（如歪头）。

### 3.2 关节与 IK（反向动力学）
- **关节点**：画布上蓝色的圆点。直接拖动圆点即可调整姿势。
- **关节旋转滑条**：拖动对应关节的滑条精确旋转。
- **关节拉伸**：勾选后拖动关节不仅可以旋转，还能拉长/缩短肢体。
- **隐藏关节点**：勾选后画布上不显示圆点，方便截图。
- **关节固定 (IK)**：开启“启用”后，点击 `左脚`、`右手` 等按钮，该关节就会被“钉”在原地，此时移动躯干，肢体长度会自动伸缩以适应固定的点（红色关节表示已固定）。

### 3.3 发光与特效
- **描边阴影**（原「轮廓外发光」）：颜色、不透明度、羽化、扩展、X/Y 偏移、连同绑定配饰；全部参数都参与关键帧和补间。
- **侧面高光**：让火柴人看起来有立体感，可调高光粗细和方向。
- **手部渐变**：让手臂末端呈现渐变颜色。
- **地面阴影**：开启后自动在脚下生成阴影，可独立调节颜色、透明度、宽度拉伸、高度拉伸（开启后在“发光”面板展开时可直接在画布拖动阴影）。
  **每个火柴人各自独立**，所以可以分别给它们打关键帧 —— 例如让某个人物在落地瞬间才出现影子。
- **深色处理**：将左臂和左腿（后方肢体）自动变暗，增强空间感。

### 3.4 画笔（橡皮擦）
- **矢量橡皮擦**：使用圆形笔刷擦除火柴人、图片或形状。
- **直线模式**：只画起点到终点的直线。
- **末端吸附（QuickShape）**：画完后笔尖停在末端不要抬起，会自动吸附成直线、圆、矩形等标准图形；
  按住拖动可改大小和角度，再停一下可在候选图形之间轮换。
- **优势**：擦除是矢量的，不破坏原像素，会跟随物体移动、旋转和缩放。支持撤销和清除本帧/全部擦除。

### 3.5 画布设置
- **背景与网格**：仅改变编辑时的外观，不影响导出结果。
- **画布边界**：开启后，导出仅保留画布框内的内容。可调节比例（1:1、16:9 等）。
- **地面参考线**：画一条绿色的辅助线，方便对齐脚部，同样不影响导出。

### 3.6 主题设置
- 可自定义面板背景、按钮颜色、文字颜色等，支持保存为“我的主题预设”。

## 4. 时间轴与帧动画制作

点击右下角 `🎬 帧动画面板`，顶部是帧列表，底部是操作按钮。

### 4.1 基础帧操作
- **＋ 帧**：在当前帧后插入一个空白/克隆帧。
- **⧉ 复制帧**：复制当前帧。
- **🗑 删除帧**：删除当前帧。
- **多选**：勾选“多选”后，点击帧块可以选中多个帧，支持多选补间、删除、导出 PNG / GIF。
- **拖拽排序**：鼠标按住帧块直接拖动，或触屏长按 300ms 拖动，可以调整帧的顺序。

### 4.2 关键帧（v7.0 起的主力方式）

时间轴现在是「关键帧 + 派生帧」：你只摆两个关键帧的姿势，中间的帧是**算出来的**，不占存储、也不会互相打架。

1. 播放头移到某一帧，点 `◆ 设关键帧`（或按 `K`）—— 当前姿势就锁成了关键帧。
2. 移到另一帧、改姿势，再按一次 `K`；两帧之间立刻出现一整段自动补出来的画面。
3. **主轨 / 子轨**：主轨按 `K` 只给「这一帧参数真的变了」的元件打关键帧；要单独锁住某个元件，切到它的子轨再按 `K`。
4. **段曲线**：点 `▾ 匀速` 改的是**当前这一段**（相邻两个关键帧之间）。先选中元件，曲线只作用于它的这一段，既不会影响别的段，也不会影响别的元件。
5. **删关键帧 ≠ 清空**：删中间的关键帧 → 前后两段自动合并补满；删末尾 → 之后所有帧静止延续这个姿势；删开头 → 之前所有帧都变成它的复制帧。
6. **复制关键帧**得到的是新的关键帧，不是普通帧。
7. **「插 N 帧」按钮会看情况变身**：当前帧后面还有关键帧 → 显示「插 N 帧」，插的是由两端关键帧算出来的派生帧；
   当前帧后面没有关键帧但后面还有帧 → 显示「补间 N 帧」，在当前帧和下一帧之间补出过渡帧；
   已经是最后一帧 → 仍然是「插 N 帧」，复制当前姿势往后续画。

> 旧版的 `✨ 补间` 仍然保留（见下一节），但新工程建议直接用关键帧。

### 4.3 补间动画（自动生成中间帧 · 兼容旧流程）
假设你要让火柴人从 A 点移动到 B 点：
1. 在第 1 帧摆好姿势（A 点）。
2. 点击 `＋ 帧` 创建第 2 帧，把火柴人移到 B 点。
3. 选中第 1 帧，点击 `✨ 补间`，输入补间帧数（如 10），点击确定。
4. **缓动曲线**：点击补间旁边的 `▾ 匀速` 可以切换缓入、缓出、缓入缓出或自定义贝塞尔曲线。
5. **🎯 分部缓动**：点击“分部”，可以单独为位置、缩放、旋转、各个关节设置不同的曲线。

### 4.4 高级动画功能
- 点击 `⚙️ 高级设置`：
- **FPS（帧率）**：调节每秒播放的帧数（默认 12）。
- **洋葱皮**：开启后，画布上会半透明显示前一帧（橙色）和后一帧（蓝色）的残影，方便调整动作。
- **全局属性修改**：勾选后，修改颜色、线条粗细、比例等属性会同步应用到该元件的所有帧。
- **清空所有帧 / 清空非当前帧**：快速重置工程。

### 4.5 轨道模式（v7.4 · 类 AM / 剪映的多轨视图）

控制栏最左边那颗 **🎞 轨道** 按钮可以把「帧块视图」切换成「轨道视图」：每个元件占一行，
它出场的帧合成一条长条，像 AM / 剪映那样**直接拖长条就能改时间**。

- **位置**：开着轨道时，时间轴会临时落到屏幕**最底部** —— 轨道面板在控制面板下方，
  控制面板和它的底部入口栏永远压在轨道面板之上，不会被挡住。关掉轨道模式后恢复原来的置顶/置底。
- **切换**：点 `🎞 轨道` 开 / 再点一次关。关掉就回到原来的帧块视图，帧块、拖帧、多选、补间全部照旧，
  两套视图共用同一份数据，不存在「两条时间轴」。
- **拉长 / 缩短**：拖长条的**左右两端**。拉长 = 补普通帧、保持当前姿势（**不会顺便加关键帧**）；
  缩短 = 腾空的那几帧真正消失。
- **整段平移**：按住长条**中间**拖动。不会撞进相邻的长条里，挪走留下的空档就是空档。
- **关键帧可以拖**：长条中间那些**白色菱形**就是关键帧。抓住它拖到别的帧 = 把这一帧挪到
  那一帧（原帧交还给自动补间）；按住 **Alt** 拖 = 复制到落点（原帧留着）。
- **分割**（剪映式）：点一条长条选中它，把播放头挪到段**中间**，点 `✂ 分割` ——
  当前段就在这一帧断成左右两段，两段都还在、各自能拖（分割点上有颗红菱形）。
- **删除**：选中一段后点 `🗑 删除`，这一段变成空白，前后自动接上。
- **关键帧**：按钮只作用于**当前选中的那条长条**所在的元件（不用再切子轨）。
- **点一下长条**（不拖）= 选中这段并选中这个元件（不跳帧），行和长条都会高亮。
- **眼睛**：每行最左边的眼睛 = 全帧显示 / 隐藏这个元件。
- **刻度缩放**：刻度尺左边的 `−` `＋` 改每一帧的宽度。缩到很小（每帧 ≤13px）时
  刻度自动改成 **分:秒**（`0:00 0:01 0:02…`），和剪映一样。
- **播放头**：红色竖线画在**当前帧的正中间**（不是格子左边），点轨道空白处可以直接跳帧。
- **面板高度**：拖面板上沿那道小横杠可以随时改轨道区高度，松手后记住下次还是这个高度。
- 手机端默认不自动开轨道模式（屏幕矮），需要时手动点 `🎞 轨道` 即可。
- 轨道模式下控制栏的顺序是：`← 播放 →` → `分割` → `删除` → `复制帧` → `粘贴帧` → `关键帧` → `插 N 帧` → `曲线`；
  帧/复制帧/删除帧/多选/子轨选择器都会暂时收起，回到帧块视图原样复原。
- **取消关键帧不会切断长条**（v7.4.2）：关键帧的规则和帧动画面板完全一致 ——
  取消只是把这一帧退回普通帧，长条该多长还是多长；只有 `分割` 才会切段。
- **段内改动作自动变关键帧**（v7.4.2）：一条轨上前（后）已经有关键帧时，
  你在别的帧上改动作，那一帧会自动升起成关键帧（和帧块视图里的老规则一致）。
  拉长出来的尾巴帧同样适用，不会再出现「改了动作却没有菱形」的情况。
- **配饰跟着主体伸缩**（v7.4.2）：画笔、贴件这类绑在火柴人身上的元件，
  主体长条拉长 / 缩短时它们会同步跟着伸缩，不用一条条再拖。
- **缩略图**（v7.4.2）：高级设置里「帧缩略图」打开时，长条会铺成一格一格的小图（像 AM 的胶片条）；
  关掉就退回纯色长条。
- **关键帧多选**（v7.4.3）：`Ctrl / ⌘ / Shift` 点菱形可以加选、再点一次取消；
  **双击**任意一颗 = 选中这一整条轨上的全部关键帧。选中的菱形会变大、描绿边。
- **整组平移**（v7.4.3）：按住在已选中的菱形的其中一颗上拖，整组按同一格数一起走
  （`Alt` 改成整组复制）。拖完 = 一步撤销。
- **复制 / 粘贴关键帧**（v7.4.3）：选中后点 `⧉ 复制帧` 或 `Ctrl/⌘+C`，
  把播放头挪到目标帧点 `📋 粘贴帧` 或 `Ctrl/⌘+V` —— 会按复制时的**相对间距**铺开，
  粘完自动选中新粘出来的那几颗，可以接着整组拖。`Delete` 删掉选中的关键帧（画面留着，只摘掉关键帧身份）。
- **落帧策略三分支**（v7.4.3）：改动作时这个关键帧该落哪儿，跟 Alight Motion 一个规则 ——
  ① 已经是关键帧 → 就地改；② 段内的派生帧 → 升起成关键帧（这就是「改了动作却没生成画面」的病根）；
  ③ 段外的普通帧 / 空白帧 → 只要这条轨已经有关键帧就落一颗，一帧关键帧都没有时按烘焙帧处理。
- **一次手势 = 一步撤销**（v7.4.3）：整组拖动、批量粘贴、批量删关键帧都走事务记账，
  拖了半天其实没动的话不会留下一条空历史（按撤销不会「按了没反应」）。
- **改动作立刻补间**（v7.4.4）：一条段里已经有关键帧时，你在后面某一帧改动作 ——
  新落下的关键帧会马上把这一段中间帧交给补间接管（没选曲线就是匀速），
  不会再出现「菱形生成了、中间却一动不动」。
- **配饰也补间**（v7.4.4）：绑在火柴人身上的画笔 / 贴件打上关键帧后，
  位移、旋转、缩放、透明度一样在两个关键帧之间插值，跟着主体一起动。
- **点轨道 = 选中元件**（v7.4.4）：点某一行轨道（长条或空白处）除了把播放头挪过去，
  还会把这一行的元件设成当前选中，左上属性面板立刻能改它。
- **长条两端的 ‹ ›**（v7.4.4）：选中长条后两端显出箭头，直接拖它们改这一段的头 / 尾
  （和原来靠边缘判定拖动的逻辑是同一套，只是现在看得见了）。
- **空白处拖 = 框选**（v7.4.4）：在轨道空白处按住拖，拉出选框扫过几条就选中几条，
  可以整组平移、`Delete` 一起删（一步撤销）。
- **缩短不残留**（v7.4.4）：轨道改短后，落在新长度之外的关键帧会被清掉，
  长条空白处不会再冒出看不见、点不着的隐藏关键帧。
- **改动作不再只动一个部位**（v7.4.5）：先拖手臂、再拖腿，两次改动都会进补间。
  以前第二次改动因为「这一帧已经是关键帧了」直接返回，段内派生帧还留在缓存里，
  播放时只有第一个改的部位在动 —— 现在每次改完都会重算段内帧。
- **点时间轴不丢选中**（v7.4.5）：点帧块 / 拖播放头只换帧，不动「当前选中的元件」。
  这也是上面那条的前置条件：选中一没，自动关键帧就把当前元件当成「非选中件」，菱形落不下来。
- **曲线标签跟着段走**（v7.4.5）：换帧、换元件、点轨道都会重新读「播放头所在那一段」的曲线，
  应用了缓入就显示缓入，不会再停在初始的「匀速」。
- **裁短会定格尾巴**（v7.4.5）：一条轨上有 1 / 6 / 17 三颗关键帧，把右端拖到 14 ——
  17 取消，7~14 保留并定格成第 6 帧的姿势；拖左端吞掉 1、6 时同理，
  留下的部分定格成 17 的姿势。改短后的末帧不会再被「段外清理」吃掉。
- **框选可以从面板任意处起手**（v7.4.5）：轨道行、左侧标签列、刻度尺、行间空隙都能按下拖动框选。
- **点空白也不掉选中**（v7.4.6）：轨道面板任意处单击 —— 行内空白、行间空隙、左侧标签列 ——
  都只挪播放头，不再把正在编辑的那条轨取消选中。想清选择按 `Esc`。
- **框选配色跟随主题**（v7.4.6）：选框的边框和底色由主题主色（`--color-primary`）压暗后算出，
  换皮肤就跟着换，不再是写死的深绿。
- **时间轴尾巴跟着轨道收**（v7.4.6）：把最后一条轨裁短 / 删掉尾部之后，
  时间轴总长会收到「最后一个真正出场的帧」，末端不再挂一串谁都不出场的空白画面。
- **移动端也能导出 MP4**（v7.4.6）：手机浏览器普遍不支持 `MediaRecorder('video/mp4')`，
  以前直接报「不支持 MP4 录制」。现在自动改走 WebCodecs（`VideoEncoder` + H.264）编码，
  再用内置的 mp4-muxer 封装成 MP4；桌面浏览器仍然优先用 `MediaRecorder`，两条路谁通用谁。
- **导出只到最后一个有内容的帧**（v7.4.6）：视频长度按「最后一个非派生帧」算，
  不再把末尾的空帧录进成片。

> 轨道视图只**读**关键帧数据，一次拖拽 / 一次按钮才写回一次，每次操作 = 一步撤销，
> `Ctrl+Z` 能一步步退回。分割点记在关键帧自己的 `__k.cut` 里（跟着工程一起保存），
> 不会漏到段内的派生帧上，所以点别处、切帧、撤销都不会让段落散架；
> 旧的工程文件打开也完全正常。

## 5. 摄像机与取景框

如果你需要导出特定比例的视频（如 16:9 短视频）：
1. 展开 `＋ 添加物体`，点击 `🎥 摄像机`。
2. 在控制面板调整摄像机的比例（16:9、9:16、1:1 等）。
3. 在时间轴轨道选择器中，选择摄像机所在的子轨道。
4. 此时画布会变成摄像机取景视角。在框内拖动可以平移摄像机，双指缩放或滚轮可以缩放摄像机取景框。
5. 摄像机也可以做动画（打关键帧）。

## 6. 导出与保存

### 6.1 导出图片 / 序列帧
- **导出 PNG / JPG**：点击面板顶部按钮，可选择高清导出（4 倍分辨率）。
- **导出 PNG 序列**：在时间轴高级设置中，将每一帧打包成 ZIP 下载。
- **多选 PNG**：在多选模式下，只导出选中的帧。

### 6.2 导出 GIF
- 在高级设置中点击 `导出 GIF`。
- 可开启“透明底”（背景透明）和“3x 高清”。
- iOS 用户导出后长按图片保存到相册。

### 6.3 导出视频
- **导出 WebM**：支持透明底的视频格式。
- **导出 MP4**：不支持透明底，但兼容性好，可自定义背景色。

### 6.4 保存动作与预设
- **保存动作**：在高级设置底部，输入动作名称（如“跑步”），将当前动作保存到动作库，可随时应用到其他火柴人身上。
- **本地预设**：保存单个火柴人的外观、颜色、比例。
- **保存项目**：
  - **💾 保存项目**：保存到浏览器缓存。
  - **📤 导出项目 / 📥 导入项目**：保存为 `.json` 文件，方便分享或备份。
  - **自动存档**：编辑器每 20 秒会自动将进度保存在浏览器后台，刷新网页不会丢失。

## 7. 快捷键与实用技巧

### 快捷键
| 按键 | 功能 |
| --- | --- |
| `C` | 复制当前选中物体 |
| `Delete` / `Backspace` | 删除当前选中物体 |
| `Space` (空格) | 播放 / 暂停动画 |
| `←` / `→` (方向键) | 切换到上一帧 / 下一帧 |
| `R` | 重置当前选中物体的姿势 |
| `Ctrl + Z` / `Cmd + Z` | 撤销 |
| `Ctrl + Y` / `Cmd + Shift + Z` | 恢复 |
| `Escape` | 关闭弹出的菜单或窗口 |

### 💡 核心技巧
1. **想做复杂的连招？** 给每个火柴人使用**独立的子轨道**（时间轴上的下拉菜单选择）。不同轨道互不干扰。
2. **火柴人太密了总是选错？** 点击上方的“图层列表”图标进行选择，或者在“层级”面板调整图层，将遮挡的肢体放到底部。
3. **橡皮擦提示受限？** 确保你选中了对象。橡皮擦只对当前选中的对象生效，并且关闭擦除模式时不会退出选择。
4. **缩放时想保持比例？** 使用自由缩放，浏览器会自动记住你调整的面板尺寸（强制刷新浏览器即可看到记忆生效）。
5. **避免画面抖动**：补间动画如果生成了不需要旋转的帧（例如原地不动），确保起始帧和结束帧的角度完全一致。
