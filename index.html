📖 简易使用说明 (点击展开)
1. 控制面板从上到下：
• 最上方是导出PNG / 导出JPG / 全屏，可勾选高清（4 倍分辨率）。
• 「＋ 添加物体」可折叠展开：火柴人、插入图片、上传配饰、对话框、内置形状都在里面。
• 下方是复制、删除、重置，再往下是「更多设置」与本地预设。

2. 基础操作：
• 选中：点击画布中的物体，或在元件列表点击。
• 移动：拖动画面上方的 ✥ 手柄，或直接输入 X / Y 坐标；拖火柴人骨盆/躯干可整体移动。
• 旋转：基础属性栏旋转数值可输入任意角度（不受 ±180 限制），也可点击 🔄 打开旋转手柄在画面上拖动旋转；图片/配饰/图形可点击 ⚓ 设置自定义锚点，旋转围绕锚点进行。
• 关节：拖蓝色关节点调整姿势，红色点为已固定的关节。
• 视角：PC 端拖空白处平移、滚轮缩放；移动端双指拖动平移、捏合缩放。

3. 更多设置（小按钮）：
• 层级、比例、关节、发光、画布、主题依次排列，点哪个按钮就展开哪个面板，再点一次收起；固定 (IK) 已并入“关节”面板底部。
• 比例面板同时包含小手小脚参数。
• 发光面板同时包含高光、渐变、地面阴影、深色处理。
• 画布面板可设置画布边界与地面参考线，开启后导出仅保留画布内容；点击画布内部可选中画布，用“缩放”缩放，拖边框移动。可开启暗角遮罩并调节透明度。

4. 帧动画与高级设置：
• 点右下角「🎬 帧动画面板」，用「＋ 帧」或「复制帧」制作动画；补间按钮旁「▾」可切换缓动曲线，「🎯 分部」可为位置、缩放、旋转以及各个关节分别设置曲线。
• 补间支持缩放与旋转，旋转可跨越 360° 生成多圈转动（如 0°→360° 顺时针一圈，0°→-720° 逆时针两圈）。
• 时间轴支持多选复制（勾选多选后按住 Shift 或连续点击可多选）。
• 高级设置里可调节 FPS、洋葱皮、帧缩略图预览、导出 GIF / PNG 序列 / WebM 视频（支持透明底） / MP4 视频（不支持透明底，可自定义背景色）、导入参考视频，以及全局属性修改开关。
• 快捷键：C 复制、Delete 删除、空格 播放/暂停、方向键 切换帧。

5. 保存与导出：
• 本地预设可保存当前火柴人的外观与颜色；预设列表支持重命名与删除。
• GIF / 视频支持透明底（视频需浏览器支持 WebM Alpha），iOS 端长按图片即可保存。
